# Мультивыбор дат для услуг

## Описание

Реализован функционал выбора **нескольких дат** при добавлении или редактировании услуги в панели управления бизнесом.

## Что изменилось

### 1. **Frontend-изменения**

#### Календарь (`CalendarField`)
- Изменён с однодневного выбора на мультивыбор
- Параметр `value` теперь принимает массив дат (`Date[]`)
- Callback `onChange` работает с массивом дат
- При клике на дату: если она выбрана — удаляется из массива, если нет — добавляется
- Выбранные даты отображаются синим цветом и остаются выделены при переключении месяца

#### Форма услуги (`ServiceFormData`)
- Добавлено поле `dates: Date[]` для хранения выбранных дат
- При сохранении даты конвертируются в ISO-8601 строки формата `YYYY-MM-DD`

#### Отображение выбранных дат
- Ниже календаря показаны чипы (теги) с выбранными датами, отсортированные по времени
- На каждом чипе можно нажать кнопку `×` для быстрого удаления даты
- Чипы исчезают, если даты не выбраны

#### Таблица услуг
- В строке услуги отображается индикатор количества выбранных дат
- Пример: "**Дата**: 3 даты" (только для услуг, не для товаров)

### 2. **Типы данных**

#### `BusinessService` в store
```typescript
type BusinessService = {
  // ... существующие поля ...
  dates?: string[];  // ISO-8601 даты: ["2025-03-15", "2025-03-20"]
};
```

### 3. **Сохранение данных**

#### При создании услуги
```typescript
await addService(businessId, {
  // ... другие поля ...
  dates: data.dates.length > 0 
    ? data.dates
        .sort((a, b) => a.getTime() - b.getTime())
        .map((d) => d.toISOString().split("T")[0])
    : undefined,
});
```

#### При редактировании услуги
```typescript
await updateService(businessId, serviceId, {
  // ... другие поля ...
  dates: data.dates.length > 0
    ? data.dates
        .sort((a, b) => a.getTime() - b.getTime())
        .map((d) => d.toISOString().split("T")[0])
    : undefined,
});
```

### 4. **Хранение в компоненте**
- Даты хранятся как `Date[]` для удобства работы с календарём
- При загрузке существующей услуги даты парсятся из `service.dates` (массив ISO-строк)
- При сохранении даты форматируются в ISO-8601 для передачи

## Использование

### Добавление услуги с датами
1. Откройте "Добавить услугу"
2. Выберите один или несколько дней в календаре
3. Выбранные даты появятся как чипы ниже календаря
4. Нажмите "Сохранить услугу"

### Редактирование существующей услуги
1. Откройте услугу на редактирование
2. Ранее выбранные даты загружаются и отображаются в календаре
3. Добавляйте или удаляйте даты по необходимости
4. Сохраните изменения

### Удаление даты
- Нажмите на чип с датой → на `×` справа
- Или переклацайте дату в календаре

## Текущие ограничения

- ✅ Даты хранятся **локально** в состоянии компонента и в store
- ⚠️ **Серверное сохранение** пока не реализовано (нет endpoint'а в backend)
- ❌ Даты **не синхронизируются** между устройствами без backend'а

## Для backend-интеграции

Когда будет готов backend, необходимо:

1. **Расширить API-контракт сервиса:**
   ```typescript
   type ServiceCreate = {
     // ... существующие поля ...
     available_dates?: string[];  // ISO-8601 даты для услуги
   };
   
   type ServiceUpdate = Partial<{
     // ... существующие поля ...
     available_dates?: string[];
   }>;
   ```

2. **Обновить функции синхронизации** в `lib/api/businessSync.ts`:
   - `createServiceOnApi()` — передавать `available_dates` в payload
   - `updateServiceOnApi()` — передавать `available_dates` в payload

3. **Обновить mapper** в `lib/api/mappers.ts`:
   - `apiServiceToBusinessService()` — маппить `available_dates` → `dates`

## Файлы, которые изменились

- `src/components/features/business/BusinessDashboard.tsx` — главный компонент с формой и календарём
- `src/store/business.store.ts` — добавлено поле `dates` в `BusinessService`

## Тестирование

1. Соберите проект: `npm run build` ✓
2. Откройте панель управления бизнесом
3. Добавьте или отредактируйте услугу
4. Выберите несколько дат в календаре
5. Убедитесь, что даты отображаются как чипы
6. Сохраните услугу
7. При повторном открытии услуги даты будут загружены и выделены в календаре

---

**Примечание:** Даты сейчас остаются в памяти браузера. При перезагрузке страницы с другого устройства даты будут пусты, пока backend не сохранит их на сервер.
